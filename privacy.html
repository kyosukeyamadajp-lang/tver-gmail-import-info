概要プライバシー利用条件

プライバシーポリシー

対象アプリ：TVer Gmail Import

アクセスする情報と目的

利用者本人のGoogleアカウントにOAuthで接続し、指定した検索条件に一致するメールの件名、送信元、到着日時、本文、ラベルとメッセージIDを、新着通知の判定とURLの抽出のために扱います。

権限

読取専用モードはgmail.readonlyを使用します。片付けモードはgmail.modifyを使用し、URL保存後に対象通知を既読化・ゴミ箱移動します。gmail.modifyはGmail全体を読み取り・変更でき、作成・送信も可能な広い権限ですが、本ツールはメールの作成・送信・完全削除を実装していません。

保存と共有

抽出URL、OAuth認証情報、処理の件数・結果ログは利用者本人のMacに保存します。メール本文を恒久保存する機能はありません。通常ログには本文、件名、認証情報を記録しません。試運転の標準出力には候補URLを表示します。

本ツールには独自のメールデータ受信サーバー、広告、アクセス解析はありません。GoogleユーザーデータをGitHubやこの案内サイトへ送信しません。個人情報の販売、広告利用、汎用AIモデルの学習への利用も行いません。Gmail APIとの通信にGoogleを利用します。

保持と削除

URLと認証情報は本人がMac上で削除するまで保持します。通常ログは1MB・過去3世代でローテーションします。起動処理の出力ログは本人が管理します。Googleアカウントの「サードパーティ製アプリとサービス」からアクセスを取り消せます。ゴミ箱移動後のメールはGmailの保持規則に従います。

Googleユーザーデータの限定利用

TVer Gmail ImportによるGoogle APIから取得した情報の利用および他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。

管理と問い合わせ

個人のアカウント所有者が、本人のMacとGoogleアカウント上で管理します。公開サービスとして第三者のメールデータを預かる運用は提供していません。案内の誤りは、このサイトのGitHubリポジトリで報告できます。メール本文・URL一覧・認証情報は投稿しないでください。
